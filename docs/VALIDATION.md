## 已完成的本机验证

- **97 项 Python 回归测试通过**：29 项导入/统计/只读缓存适配，29 项 Jev 客户端/脱敏/分类验证，39 项真实本机 HTTP/任务/命令行与评估工具边界。
- JavaScript 语法检查通过。浏览器检查使用 Chrome，覆盖 320、390、768、1280 像素宽度，无横向溢出。
- 完整界面流程验证使用明确标注的模型测试替身：设置、导入、发送预览、部分选择、本机异步任务、覆盖率、证据修正、匿名导出、日期筛选。测试替身不是付费 Jev。
- 界面复核覆盖恶意 HTML 文本与姓名、损坏 JSON 保留原数据、临时断网后的任务恢复、未分析文本不计为中性；浏览器没有外部网络请求或 JavaScript 错误。
- 临时 SQLite 固定样例验证稳定群成员 ID、同名成员隔离、类型解析与只读导入，读取前后数据库文件字节一致。
- 隔离安装验证 wheel 包含界面资源、没有第三方运行时依赖；在源码目录外启动并读取页面、脚本、样式、示例和设置接口。

重点回归包括：消息类型不能凭文件名猜测；49 类型必须由可靠子类型识别文件；分母不含未处理文本；未知时间不被当作确定前文；相同预览重复提交复用任务；取消勾选不改变已确认前文；跳过已分析只排除目标；返回无效分类也记录已消耗 tokens；上游重定向不能携带密钥到另一个地址；Windows 管道与重定向输出使用 UTF-8，避免中文诊断信息导致命令失败。

## 真实 Jev 评估状态

**尚未完成真实 Jev 调用。** 开发任务启动时没有可用 API Key；既有账户之前使用一次性隐藏输入，凭据没有保存。离线通过和测试替身流程不能证明当前模型的中文分类效果。

已准备 `tests/fixtures/jev_eval.json`：36 条完全虚构案例，32 条中文、4 条英文，包含明确正负面、中性、混合、反讽、引用他人情绪、简短歧义、事实技术故障和注入攻击。参考标签在调用前编写，存在合理歧义的案例允许多个参考选项。

在本机设置页配置自己的 Key 后运行：

```sh
python3 tools/evaluate.py --output private/jev-evaluation.json
```

脚本通过本机应用的预览与任务接口发起评估，不读取密钥。输出包含实际模型版本、tokens、请求数量、错误、各维度参考一致率和逐条比较。默认阈值 0.55 是产品规则；Jev 返回的置信度描述概率分布集中程度，不等于准确率。应对差异案例作人工复核后再调整提示和统计规则。

**当前没有可发布的真实模型一致率，也没有宣称无缺陷或人格判断准确率。**

## 微信接入范围

已核对公开存在的 [huohuoer/wechat-cli](https://github.com/huohuoer/wechat-cli)，兼容缓存适配器针对 0.2.4 / `a3789232d4f79bf0b30634d9dadbce71e4acd601`。未将该第三方工具捆绑进本项目。

开发机未安装、初始化 WeChat CLI，因此**未验证真实微信账号的端到端读取**。适配兼容证据是公开源码与合成数据库测试。已有缓存缺失或过期时不会自动扫描密钥或解密。原生群导出若只有显示名、没有稳定发送者 ID，会明确拒绝，以免将同名成员合并。

本机记录不保证覆盖手机端全部历史；采样情绪不能直接代表完整聊天，更不能推断人格、心理健康或真实内心。表情包、语音和文件只统计类型与次数，不解析本体。
